# 🌸 Iris Flower Classification

This project uses Machine Learning to classify Iris flowers into three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## Machine Learning Model

Logistic Regression

## Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- NumPy
- Scikit-learn
- Streamlit

## Web Application

The machine learning model is deployed using Streamlit Community Cloud.
